Sincronização Instagram — Seção de Eventos

ONG Amor Animal Marília

Documento técnico — Agosto 2026

1. Visão Geral

A funcionalidade de Sincronização com Instagram permite importar automaticamente as postagens da conta oficial da ONG (@grupoamoranimal) para a seção de Eventos do site amoranimal.ong.br, mantendo o conteúdo sempre atualizado sem necessidade de cadastro manual.

Conta sincronizada:

https://www.instagram.com/grupoamoranimal/

Quando o administrador clica no botão "Sincronizar Instagram", o sistema consulta as postagens mais recentes da conta, seleciona aquelas que ainda não foram publicadas no site e cria automaticamente os respectivos registros de evento.

2. Onde Aparece na Interface

Página Inicial (index.html)

  • Na seção "Eventos", ao lado do título, há um botão verde-água com ícone de refresh.
  • O botão possui a classe admin-only — só é visível para usuários autenticados como administradores.
  • Rótulo: "Sincronizar Instagram".

Página de Eventos (pages/eventos.html)

  • No topo da página, ao lado do título "Eventos", está o mesmo botão de sincronização.
  • Visível apenas no modo admin (body.admin-mode).
  • Ao clicar, exibe spinner e texto "Sincronizando…".
Acesso restrito: O botão só aparece quando o usuário está logado com perfil de administrador. Na ausência de login, o botão permanece oculto (display:none).

3. Fluxo da Sincronização

1
O administrador clica em "Sincronizar Instagram".
2
O botão fica desabilitado e exibe um spinner ("Sincronizando…").
3
Uma requisição POST é enviada para /eventos/sync-instagram na API.
4
O servidor busca as postagens recentes da conta @grupoamoranimal.
5
Para cada post com foto, o servidor cria um registro de evento (título, data, foto, link).
6
A API retorna um JSON com o resultado da operação.
7
Se houve novos posts, a página recarrega automaticamente.
8
Se não houve novidades, exibe-se a data da última publicação já existente.

4. Detalhes Técnicos

Endpoint da API
POST  https://api.projetosdinamicos.com.br/amoranimal/eventos/sync-instagram

Requer autenticação Bearer token no header Authorization.

Requisição

fetch(API_BASE + '/eventos/sync-instagram', {
    method: 'POST',
    headers: {
        'Authorization': 'Bearer <token>'
    }
})

Resposta — Sucesso com novos posts

{
    "success": true,
    "publicados": 3,
    "sem_foto": 1
}

publicados: quantidade de novos eventos criados a partir de posts do Instagram.
sem_foto: posts que estavam sem imagem e foram ignorados.

Resposta — Sem novidades

{
    "success": true,
    "publicados": 0,
    "cutoff": "2026-08-20T14:30:00.000Z"
}

cutoff: data/hora da última publicação já existente no site.

Resposta — Erro

{
    "success": false,
    "error": "Falha na sincronização"
}

5. Estrutura do Evento Criado

Cada post sincronizado do Instagram gera um registro com os seguintes campos:

Campo Tipo Descrição
id INTEGER Identificador único gerado pela API
titulo STRING Legenda do post (truncada)
data_evento DATE Data de publicação do post no Instagram
descricao TEXT Texto completo da legenda do post
fotos STRING URL ou base64 da imagem principal do post
link STRING URL direta para o post no Instagram
url_instagram STRING URL alternativa do Instagram (fallback)
status STRING "Publicado" para posts sincronizados
origem STRING "instagram-sync" — indica a origem da sincronização

6. Comportamento do Botão de Sincronização

O fluxo completo do JavaScript (sincronizarInstagram) é:

async function sincronizarInstagram(btn) {
    if (btn.disabled) return;
    btn.disabled = true;
    var htmlOriginal = btn.innerHTML;
    btn.innerHTML = '<span class="spinner"></span> Sincronizando...';

    try {
        var r = await apiFetch('/eventos/sync-instagram', {
            method: 'POST'
        });
        var d = await r.json();

        if (d.success && d.publicados > 0) {
            alert(d.publicados + ' novo(s) post(s)!');
            location.reload();
        } else if (d.success) {
            alert('Nenhuma novidade.');
            btn.disabled = false;
            btn.innerHTML = htmlOriginal;
        } else {
            throw new Error(d.error);
        }
    } catch (e) {
        alert('Erro: ' + e.message);
        btn.disabled = false;
        btn.innerHTML = htmlOriginal;
    }
}

7. Exibição dos Eventos Sincronizados

Após a sincronização, os eventos aparecem na seção "Eventos" da página inicial e na página dedicada (pages/eventos.html), ordenados do mais recente ao mais antigo.

Elementos visuais de cada card de evento

  • Foto do evento (imagem do post do Instagram).
  • Título (legenda do post).
  • Data de publicação formatada (dd/mm/aaaa).
  • Descrição (texto completo da legenda).
  • Botão "Ver no Instagram" — link direto para o post original.
  • Badge de status ("Publicado") no rodapé do card.
Ordem de exibição: Os eventos são ordenados por data de criação (created_at ou origem), do mais recente ao mais antigo, usando a função sort() no JavaScript.

8. Conta do Instagram Vinculada

A URL da conta é definida diretamente no código-fonte das páginas:

var INSTAGRAM_URL = 'https://www.instagram.com/grupoamoranimal/';

Essa URL é usada como fallback quando um evento não possui link próprio do Instagram. Também é exibida no botão "Ver no Instagram" de cada card.

9. Controle de Acesso

A funcionalidade de sincronização é restrita a administradores:

  • O botão possui a classe CSS admin-only que o oculta por padrão.
  • Apenas quando o body do documento possui a classe admin-mode o botão é exibido.
  • A classe admin-mode é adicionada automaticamente quando um administrador faz login.
  • A requisição à API requer um token Bearer válido no header Authorization.
  • Tokens expirados são removidos do localStorage automaticamente.
Autenticação: O token é armazenado em localStorage com a chave 'amoranimal_token' e possui um tempo de expiração controlado por 'amoranimal_session_expiry'.

10. Resumo

A sincronização Instagram Eventos é uma ferramenta que automatiza a publicação de conteúdo no site da ONG Amor Animal Marília. Ao clicar em um único botão, o administrador importa todas as postagens recentes da conta @grupoamoranimal, criando eventos automaticamente com título, data, descrição, foto e link para o post original.

O sistema evita duplicidades, filtra posts sem foto e mantém os eventos sempre ordenados cronologicamente. Todo o processo é seguro, restrito a administradores, e utiliza autenticação por token.
